# tileylab/pate: Output

## Introduction

This document describes the output produced by the pipeline.

## Pipeline overview

The pipeline produces the following output directories:

### `PHASED/`

Per-locus FASTA files containing phased haplotype sequences for each sample.
Each sequence header follows the format `>SAMPLE__LOCUS__ALLELE_NUMBER`.

When `--unique_only` is set (default), only distinct haplotype sequences are output.
When disabled, the expected number of alleles (matching ploidy) are output, which may
include identical sequences.

### `GENOTYPE/`

Per-locus FASTA files containing unphased genotype sequences with IUPAC ambiguity
codes at heterozygous positions.

### `PICKONE/`

Per-locus FASTA files with a single randomly chosen allele per sample per locus.
Useful for phylogenetic analyses requiring one sequence per sample.

### `summary_stats/`

- `{sample}.phasingSummary.txt` - Per-locus statistics for each sample including:
  variant count, heterozygosity, number of phasing blocks, longest block length,
  and allele count distribution.
- `averagePhasingStats.txt` - Aggregate statistics averaged across all loci per sample.

### `references/`

Per-sample concatenated reference FASTA files built from the input per-locus references.

### `iupac/`

IUPAC-coded consensus FASTA files generated by GATK FastaAlternateReferenceMaker.

### `phasing/`

H-PoPG phase output files (`.phase.out` and `.phase.log`) for each sample x locus
combination.

### `multiqc/`

[MultiQC](http://multiqc.info/) report aggregating quality metrics from FastQC,
samtools stats, and pipeline information.

### `pipeline_info/`

Nextflow execution reports: timeline, trace, DAG, and software versions.
